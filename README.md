# Yield Balance

Yield Balance는 사용자가 입력한 목표수익률, 위험허용도, 최소 현금성 자산 비중, 보유 자산 정보를 기준으로 자산군 단위 목표배분과 리밸런싱 참고 금액을 계산하는 내부 MVP입니다.

이 저장소의 구현은 Phase 0 내부 계산기와 Phase 1 MVP 기반 구조를 포함합니다. 현재 데이터는 브라우저 로컬 저장소에 저장되며, Prisma 스키마와 시드 스크립트는 서버 저장 구조 확장을 위한 기반입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

프로덕션 빌드 확인:

```bash
npm run build
npm run start
```

Prisma Client 생성:

```bash
npm run prisma:generate
```

PostgreSQL 연결 후 시드 실행:

```bash
npm run prisma:seed
```

## 테스트 방법

```bash
npm test
```

현재 엔진 테스트는 다음 항목을 검증합니다.

- 목표배분 밴드 매핑과 12% 이상 제한
- 포트폴리오 기대수익률, 세후 참고 수익률, 총수익률
- 위험점수 구성 요소
- 자산군별 조정 필요 금액과 상태 우선순위
- 월 신규 투자금의 현금 우선 및 부족 비중 배분
- 고분배 착시 경고 단계

## 내부 비율 규칙

코드 내부의 수익률과 비중은 모두 소수로 저장합니다.

- 10%는 `0.10`
- 8.3%는 `0.083`
- 화면 표시 시에만 퍼센트 형식으로 변환합니다.

## 주요 계산 공식

자산 기대수익률:

```text
인컴수익률 + 기대 가격수익률
```

포트폴리오 기대수익률:

```text
Σ(자산 비중 × 자산 기대수익률)
```

연 예상 인컴 금액:

```text
Σ(원화 평가금액 × 인컴수익률)
```

세후 참고 수익률:

```text
인컴수익률 × (1 - 인컴 참고 세율)
+ max(기대 가격수익률, 0) × (1 - 가격수익 참고 세율)
+ min(기대 가격수익률, 0)
```

총수익률:

```text
인컴수익률 + 연환산 가격 변화율 + 환율 변화율
```

위험점수:

```text
자산구성 점수 × 0.30
+ 집중도 점수 × 0.20
+ 현금 부족 점수 × 0.20
+ 가격 하락 점수 × 0.15
+ 환노출 점수 × 0.10
+ 유동성 점수 × 0.05
```

월 신규 투자금 배분:

```text
1단계: 현금성 자산 비중이 최소 기준보다 낮으면 현금성 자산에 먼저 배분
2단계: 남은 금액을 목표비중 대비 부족 금액 비율로 배분
```

## 시드 데이터

상수 파일과 Prisma 시드가 같은 기준을 사용합니다.

- `src/lib/constants/asset-types.ts`: 자산군 enum, 기본 인컴수익률, 기대 가격수익률, 위험계수, 유동성 점수
- `src/lib/constants/target-allocation-matrix.ts`: 목표수익률 5%, 7%, 10%, 12% 이상 밴드별 목표배분
- `src/lib/constants/tax-rates.ts`: 계좌 유형별 참고 세율
- `prisma/seed.ts`: `asset_type_settings`, `target_allocation_templates`, `target_allocation_items`, `tax_rate_settings` 입력

## 화면 구성

- `/onboarding`: 목표수익률, 위험허용도, 손실 허용폭, 최소 현금성 자산 비중 입력
- `/assets`: 수동 자산 등록과 원화 환산
- `/dashboard`: 기대수익률, 인컴 금액, 위험점수, 상태, 스냅샷 저장
- `/target-portfolio`: 목표배분과 현재비중 비교
- `/rebalance`: 자산군별 조정 참고 금액과 월 신규 투자금 배분

## 법무 검토 전 제한

외부 공개 전에는 법무 검토가 필요합니다. 현재 구현은 내부 계산과 자산군 단위 참고 정보 제공에 한정합니다.

구현하지 않은 항목:

- 자동매매
- 특정 종목, ETF, 채권, 금융상품 단위 추천
- 상품 단위 매수·매도 지시
- 성과를 단정하는 표현
- 레버리지 또는 파생전략
- 시장가격, 환율, 세금 확정값 자동 확정

본 서비스는 투자 수익률을 보장하지 않으며, 특정 금융상품의 매수·매도 지시나 자동매매를 제공하지 않습니다. 표시되는 수익률과 리밸런싱 정보는 사용자가 입력한 정보와 자산군 기준 가정에 따른 참고 계산 결과이며, 실제 투자 판단과 책임은 사용자 본인에게 있습니다.
